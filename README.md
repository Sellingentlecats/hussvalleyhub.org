# Huss Valley Hub — replacement site

The October 18, 2026 rebuild replaces the former visual implementation. Existing game data, official API snapshots, source logs and guide prose are retained. Code spellings now link directly to developer Discord announcements, with original excerpts. The former build and hub modules are archived under research/; their CSS is not loaded.

## Build and preview

Requires Node.js; no package install is needed.

```powershell
npm run build
npm run check
python -m http.server 4173 --bind 127.0.0.1 --directory dist
```

Open http://127.0.0.1:4173/. The current preview server is bound only to localhost. The owner approved production replacement on October 18, 2026. Deployment results are recorded in research/DEPLOY-20261018.md.

## New architecture

- build.mjs: shared layout, navigation/footer, metadata, breadcrumbs, data-driven routes, robots and sitemap.
- site/content.mjs: home, codes, calculator, tier list, wiki and ability references.
- site/style.css: entirely new charcoal/lime visual system and responsive layouts.
- site/app.js: navigation, clipboard feedback, role filter and reward/goal calculator.
- data/codes.json and game-research.json: retained source records.
- data/retained-pages.json: 14 existing page bodies retained independently of their old styles.
- data/abilities.json: publisher ranking, roles and selected dated prices; explicitly not in-game tests.
- data/game.config.json: adapted from Roblox Site Architect's template; routes are regenerated by the build.

The build creates 30 canonical content routes, three legacy aliases and a 404. Code intent now lives at /codes/; home is the game companion portal. The calculator adds reported reward units and estimates a Gem shortfall. It does not calculate farming time, guarantee reward delivery or convert Robux.

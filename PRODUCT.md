# Huss Valley Hub

## Platform and stack
English static game companion, generated by Node into dist. Roblox Site Architect template responsibilities are adapted to the existing static runtime: shared header/footer, data readers, metadata, JSON-LD, data-driven ability routes and sitemap. No React runtime is required for this preview.

## Audience and purpose
Huss Valley players finding codes, choosing abilities, planning reported rewards and learning Runner/Chaser basics.

## Scope
Home portal, dedicated codes page, reward/Gem-goal calculator, attributed tier list, wiki and ability references, guide directory and retained practical guides, official profile, update/source archive, About, Contact, Privacy and Terms. Legacy intent URLs remain available.

## Truth and constraints
Preserve existing data and research. Do not invent codes, rewards, expiry dates, gameplay tests, ability measurements or farming rates. Source review is distinct from successful in-game redemption. Tier rankings are the named publisher’s opinions. Prices are dated references. No Robux conversion or measured win-rate claim. Independent fan resource, not affiliated with Roblox or Huss Valley Official.

## Visual commitments
The former visual style is explicitly rejected by the owner. Use the new charcoal/lime game-portal system in DESIGN.md, official game artwork, condensed sans headings and sans reading type. The former homepage table-first composition is retired.

## Delivery
The owner approved replacing the existing production website on October 18, 2026. Deploy only to the existing hussvalleyhub project and hussvalleyhub.org; no other sites are in scope. The owner also authorized a daily 10:00 Asia/Shanghai Discord code-monitoring task in this chat: publish newly announced codes, archive codes with explicit expiry evidence, and synchronize the homepage after successful validation. Preserve primary message links and exact quotes; do not display verification badges or dates.
